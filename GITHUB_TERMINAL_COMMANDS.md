# GitHub Terminal Commands

Run Git commands only inside the dedicated project folder:

```bash
cd ~/Downloads/PollenAllergyRiskForecaster
git init

git add .
git status
git commit -m "Initial release - Pollen Allergy Risk Forecaster"
git remote add origin https://github.com/shaunakmirajgaonkar/pollen-allergy-risk-forecaster.git
git push -u origin main
```
